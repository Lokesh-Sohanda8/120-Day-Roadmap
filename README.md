# Learn & Build — 120-Day Command Center v2

A GitHub Pages-ready, local-first learning tracker built around:

**Learn → Practice → Build → Ship → Reflect**

## Included
- 120-day roadmap based on the selected Data Science roadmap, with Sheryians AI School links as a parallel resource.
- Daily checklist + learning journal.
- Separate learning, practice, building, shipping and revision time.
- True current/longest streaks.
- 8 milestone progression.
- Phase analytics + 120-day heatmap.
- Project pipeline with progress, status, next action and URL.
- Weekly reviews for all 120 days.
- Spaced-repetition review queue (1 / 3 / 7 / 21 days).
- Knowledge vault and question backlog.
- JSON export/import backup.
- Light/dark theme.
- PWA/offline support with service worker.
- No server, database or build step required.

## GitHub Pages
Upload the contents of this folder to the root of a GitHub repository. Enable **Settings → Pages → Deploy from branch** and choose the main branch and root directory.

## Data storage
All progress is stored in browser `localStorage`. Export a JSON backup periodically, especially before switching devices or browsers.

## Notes
The app keeps the original 120-day roadmap intact and adds the workflow/measurement layer around it.
